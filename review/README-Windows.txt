RAGAA — نظام إدارة تحصيل المنافذ (Windows)
==========================================

التثبيت
-------
1. شغّل ملف RAGAA-Setup.exe.
2. اتبع خطوات المثبت (يمكنك إنشاء اختصار على سطح المكتب).
3. يظهر البرنامج في قائمة Start باسم RAGAA.

التشغيل
------
شغّل RAGAA من قائمة Start أو من اختصار سطح المكتب.
لا تحتاج إلى تثبيت Flutter أو Visual Studio أو أي مكتبات إضافية؛
جميع ملفات DLL المطلوبة (بما فيها sqlite3.dll) موجودة داخل مجلد التثبيت.

مكان البيانات
------------
قاعدة البيانات المحلية:
    %APPDATA%\..\RAGAA\data\ragaa_accounting.db
النسخ الاحتياطية والتقارير المصدّرة (PDF / Excel):
    Documents\RAGAA\backups
    Documents\RAGAA\exports

هذه المسارات خارج مجلد التثبيت، وبالتالي:
- تحديث البرنامج لا يمس بياناتك.
- إعادة تثبيت النظام لا تمس بياناتك.
- إزالة التثبيت العادية **لا تحذف** قاعدة البيانات ولا النسخ الاحتياطية.
  احتفظ بنسخة احتياطية دورية من داخل البرنامج (شاشة النسخ الاحتياطي).

ملاحظات
-------
- الواجهة عربية بالكامل باتجاه RTL.
- اليومية (PDF / Excel) تُصدَّر من شاشة التقارير بعد اختيار «يومي» ثم التاريخ.
- يمكن فتح مجلد الملفات المصدَّرة مباشرة من الشريط الأخضر بعد التصدير.
