# RAGAA — إدارة تحصيل المنافذ

تطبيق Flutter عربي لجهاز مركزي واحد، يسجل إجمالي تحصيل كل وردية لكل منفذ.

## المرحلة الأولى
- إضافة المنافذ
- ورديتان لكل منفذ
- إدخال تحصيل وردية مع تاريخ تشغيلي
- منع تكرار سجل (منفذ + تاريخ + وردية) واستبداله بعد تأكيد
- تجميع حسب فترة تاريخية ووردية
- تخزين محلي مبدئي باستخدام shared_preferences

## التشغيل
يتطلب Flutter SDK مثبتًا.

```bash
flutter create --platforms=windows,linux,macos,android .
flutter pub get
flutter run -d windows
```

يمكن استبدال windows بـ linux أو جهاز مدعوم آخر.

## مهم قبل الاستخدام الفعلي
هذا نموذج أولي وليس نظامًا محاسبيًا إنتاجيًا. shared_preferences تخزين تجريبي وليس قاعدة بيانات محاسبية متينة. المرحلة التالية: SQLite، نسخ احتياطي واستعادة، سجل تعديلات، اعتماد ورديات، اختبارات، تصدير PDF/XLSX، وإعداد حزمة التثبيت. لا تدخل بيانات تحصيل حقيقية قبل تنفيذ النسخ الاحتياطي والتحقق.

## قواعد العمل
- كل منفذ له ورديتان: 1 و2.
- تاريخ الوردية هو التاريخ التشغيلي المحدد، حتى لو امتدت الوردية بعد منتصف الليل.
- المبالغ تخزن بالقروش كأعداد صحيحة لتجنب أخطاء التقريب.
- لكل منفذ/تاريخ/وردية سجل واحد.
- تقارير الفترة تشمل تاريخ البداية والنهاية.
