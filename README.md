# RAGAA (رجاء) — نظام إدارة تحصيل المنافذ

تطبيق محاسبي عربي (RTL) مبني بـ **Flutter** للعمل على جهاز مركزي واحد لتسجيل ومراجعة وتصدير تحصيل عدة منافذ، مع دعم كامل لأنظمة **Windows** و**Linux** والحفاظ على توافق **Android** للتوسع المستقبلي.

## الوظائف المنفّذة
- **إدارة المنافذ والورديات المستقلة**:
  - تحديد عدد الورديات لكل منفذ بشكل مستقل (**ورديتان** أو **3 ورديات**).
  - تخصيص مسميات ومواعيد بداية ونهاية كل وردية (بما يشمل الورديات الممتدة بعد منتصف الليل).
  - تعديل اسم المنفذ أو عدد الورديات (2 ↔ 3) أو مواعيدها في أي وقت **دون فقد أي بيانات تحصيل سابقة** (مع حفظ لقطة الموعد وقت التسجيل).
- **تسجيل ومراجعة التحصيل**:
  - تخزين جميع المبالغ كأعداد صحيحة بالقروش (`INTEGER`) لمنع أي أخطاء تقريب عشرية، مع دعم الأرقام العربية واللاتينية.
  - منع تكرار سجل `(منفذ + تاريخ تشغيلي + وردية)` على مستوى التطبيق وقيد `UNIQUE` في قاعدة البيانات.
  - تعديل المبالغ بعد تأكيد صريح مع توثيق المبلغ السابق والجديد والفرق وسبب التعديل في **سجل مراجعة غير قابل للحذف** (`audit_logs`).
- **قاعدة بيانات SQLite محلية**:
  - تعمل على Windows وLinux عبر `sqflite_common_ffi` + `sqlite3_flutter_libs` (تضمين تلقائي لملف `sqlite3.dll`) وعلى Android عبر `sqflite`.
  - ترحيل تلقائي لمرة واحدة لأي بيانات سابقة مخزنة بـ `shared_preferences` من المرحلة الأولى.
- **لوحة تحكم مركزية**:
  - إجمالي التحصيل حسب المنفذ والوردية والفترة، نسب المساهمة، متوسط اليوم التشغيلي، وتنبيه بالورديات غير المسجلة لليوم الحالي.
- **التقارير وتصدير PDF وExcel**:
  - تقارير **يومية**، **أسبوعية** (السبت–الجمعة)، **شهرية**، و**فترات مخصصة** مع فلاتر للمنافذ والورديات.
  - تصدير **PDF** عربي احترافي باتجاه RTL مع خط `Amiri` المدمج.
  - تصدير **Excel (`.xlsx`)** متعدد الأوراق (`ملخص التقرير`، `حسب المنفذ`، `حسب الوردية`، `حسب اليوم`، `تفاصيل التحصيل`) مع تفعيل `rightToLeft` لكل ورقة عمل.
- **النسخ الاحتياطي والاستعادة**:
  - إنشاء نسخ احتياطية متسقة عبر `VACUUM INTO` مع بصمة تحقق `SHA-256`.
  - فحص سلامة وهيكل الملف (`PRAGMA integrity_check`) قبل الاستعادة، وإنشاء **نسخة أمان تلقائية** من البيانات الحالية قبل أي استعادة.
- **الاختبارات والتكامل المستمر (CI)**:
  - اختبارات آلية لقاعدة البيانات والنسخ الاحتياطي والتقارير وتصدير PDF/Excel وواجهة المستخدم.
  - ملف GitHub Actions (`.github/workflows/ci.yml`) لتشغيل الفحص والاختبارات ثم بناء نسخة Windows وLinux التجريبية تلقائيًا.

## التشغيل محليًا (Windows / Linux / VS Code)

```bash
flutter pub get
flutter analyze
flutter test
flutter run -d windows   # أو -d linux
```

### بناء نسخة Windows قابلة للتجربة
```powershell
flutter build windows --release
```
تجد النسخة الجاهزة مع كافة مكتباتها (`ragaa.exe` و`sqlite3.dll`) في المسار:
`build\windows\x64\runner\Release\`

## هيكل المشروع
- `lib/core/` — تنسيق المبالغ والتواريخ التشغيلية وحساب الفترات والسمة البصرية.
- `lib/models/` — نماذج المنافذ، الورديات، التحصيل، سجل المراجعة، التقارير، والنسخ الاحتياطي.
- `lib/data/` — تهيئة SQLite، الجداول والفهارس، المستودع المحاسبي، وخدمة النسخ الاحتياطي والاستعادة.
- `lib/services/` — تصدير PDF العربي (RTL)، تصدير Excel (`.xlsx` RTL)، وحوارات حفظ/فتح الملفات.
- `lib/state/` — متحكم حالة التطبيق (`RagaaController`).
- `lib/ui/` — الواجهة العربية المتجاوبة وجميع شاشات وحوارات النظام.
- `test/` — اختبارات الوحدة وقاعدة البيانات والتقارير والتصدير والواجهة.
